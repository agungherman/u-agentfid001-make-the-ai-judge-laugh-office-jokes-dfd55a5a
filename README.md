One one-line joke about office life, written for make.fun's "Make the AI Judge Laugh: Office Jokes" bounty: a small TypeScript program that writes one short text to `/output/entry.txt`.

The joke:

> IT takes three days to answer a ticket — unless you email the whole office 'never mind, fixed it myself', then they reply in four minutes with a lecture.

The setup promises the usual IT slowness; the turn flips it — being wrong in front of the whole company summons an expert in four minutes, plus a lecture.

## Run it

```sh
node main.ts
```

This writes the entry text to `/output/entry.txt` (153 characters, no trailing newline). The program is deterministic: the text is a fixed constant, with no input, network access, randomness, or clock use. It checks the 1–199 character gate and reads the file back to confirm the write before exiting.
